# 💬 Real-Time Chat Application (MERN Stack)

A full-stack real-time chat application built using the MERN stack (MongoDB, Express.js, React.js, Node.js) with Socket.IO for instant messaging. Users can send and receive messages instantly without reloading the page.

---

## ✨ Features
- 🔴 Real-time messaging using Socket.IO  
- 🔐 Secure authentication system (Firebase / JWT)  
- 👤 One-to-one chat functionality  
- ⚡ Instant message delivery without page reload  
- 📱 Fully responsive design  
- ❌ Custom error handling  
- 🔄 RESTful API integration  

---

## 🛠️ Technologies Used

### Frontend:
- React.js  
- React Router  
- Context API  
- Axios  
- Tailwind CSS / Bootstrap  

### Backend:
- Node.js  
- Express.js  
- MongoDB  
- Socket.IO  
- JWT Authentication
